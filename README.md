This repository contains my Introduction to Data Science coursework, practical exercises, and learning materials.

## Technologies Used
- Python
- Jupyter Notebook

## Topics Covered
Add the topics that are actually included in your notebooks, such as:
- Data exploration
- Data cleaning
- Data preprocessing
- Data visualization
- Basic statistical analysis

## How to Run
1. Install Python and Jupyter Notebook.
2. Clone or download this repository.
3. Open a terminal in the repository folder.
4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open a notebook (`.ipynb`) and run its cells.
